### Problema observado — Caso 03

Al ejecutar tareas de desarrollo desde VS Code, el navegador en ocasiones abre direcciones o puertos que no corresponden con la aplicación esperada.

Puertos esperados del proyecto:

- Backend API: `35000`
- Admin UI: `35001`
- Tenant UI: `35002`

Durante las pruebas se observaron aperturas o redirecciones hacia otros puertos, incluyendo `55400` y `35003`.

Estos antecedentes son observaciones, NO una causa comprobada.

Debes determinar si existe realmente un defecto y dónde ocurre:

- Definición de tareas VS Code.
- Scripts Bash que inician aplicaciones.
- Scripts que abren el navegador.
- Variables de entorno, especialmente `BROWSER`.
- Configuración de Dev Containers.
- Docker Compose y publicación de puertos.
- Port forwarding de VS Code.
- Diferencia entre los puertos dentro del contenedor, del host Docker y del navegador de Windows.

No asumas que un puerto reenviado dinámicamente es incorrecto: comprueba si la URL abierta realmente conduce al servicio esperado.

+### App Shell with Navigation (React)
+For an app with several pages, put the page links in the page frame's navigation sidebar, not in the app bar. Each `InfiosNavigationTreeItem` carries its route in `data-path` and a unique `id`. Navigate on the frame's `infios-selection-change` event, and set `selectedItem` to the active item's `id` so the selection follows the URL, or `null` on a route that has no item. App-wide actions (settings, help, theme) go in `app-bar-actions`.
+```jsx
+import InfiosPageFrame from '@infios/uikit/react/PageFrame';
+import InfiosNavigationTree from '@infios/uikit/react/NavigationTree';
+import InfiosNavigationTreeItem from '@infios/uikit/react/NavigationTreeItem';
+import InfiosIconButton from '@infios/uikit/react/IconButton';
+
+const pages = [{ path: '/orders', label: 'Orders' }, { path: '/reports', label: 'Reports' }];
+const navId = path => 'nav-' + path.replace(/\//g, '-').replace(/^-/, '');
+// null on routes with no nav item; an unknown id logs "Navigation item ... not found".
+const selectedItem = pages.some(p => p.path === location.pathname) ? navId(location.pathname) : null;
+
+<InfiosPageFrame
+  background="tertiary"
+  selectedItem={selectedItem}
+  onInfiosSelectionChange={e => {
+    const path = e.detail?.selection?.[0]?.getAttribute('data-path');
+    if (path) navigate(path);
+  }}
+>
+  <span slot="app-bar-default">App Name</span>
+  <div slot="app-bar-actions">
+    <InfiosIconButton name="cog" label="Settings" onClick={openSettings} />
+  </div>
+  <div slot="navigation-tree">
+    <InfiosNavigationTree>
+      {pages.map(p => (
+        <InfiosNavigationTreeItem key={p.path} id={navId(p.path)} data-path={p.path}>{p.label}</InfiosNavigationTreeItem>
+      ))}
+    </InfiosNavigationTree>
+  </div>
+  <Outlet />
+</InfiosPageFrame>
+```
+The page frame renders slotted app-bar and navigation content as copies inside its own shadow DOM. Clicks on the copies are forwarded to theoriginals, but properties are not copied, only attributes. Pass per-item data as attributes (`id`, `data-path`, `name`, `label`), and route from the selection event rather than from click handlers on the items.

 ### Form Controls (React)
+Form controls (`InfiosInput`, `InfiosSelect`, `InfiosTextarea`, …) deliberately have no `label` attribute, because they are composed into custom components as well as used in forms. In a form, wrap the control in `InfiosFormField`: it renders the label and sets the control's accessible name from it. The control must be the form field's direct child, so put adornments in the form field's `prefix` / `suffix` slots rather than a wrapper element. When you compose a control without a form field (a search box, a control inside a custom component), set `accessible-name` (`accessibleName` in React) on the control so screen readers still announce it.

# @infios/uikit — Foundations

Design tokens and foundation utility classes for `@infios/uikit`. Tokens are CSS custom properties (`--infios-*`); foundation utilities are classes (`infios-*`). This file is generated from the token and foundation CSS sources — do not hand-edit.

## Using design tokens

Import the token and theme CSS once in your app entry point, then reference tokens with `var()`:

```css
@import '@infios/uikit/themes/tokens.css';
@import '@infios/uikit/themes/light.css';
/* Optional dark theme: @import '@infios/uikit/themes/dark.css'; */

.my-element {
  color: var(--infios-color-text);
  background: var(--infios-color-bg-surface);
  padding: var(--infios-spacing-sm);
  border-radius: var(--infios-border-radius-md);
}
```

Design tokens are custom properties, so they inherit across the shadow DOM boundary: inside a Lit component you can use `var(--infios-*)` directly in the component's own styles, with nothing to import.

### Semantic token usage rule

Always style with **semantic** tokens (e.g. `--infios-color-text-primary`, `--infios-color-bg-surface`, `--infios-color-border`) — never the raw **primitive** palette tokens (e.g. `--infios-color-acce2`, `--infios-color-neutral1`). Semantic tokens carry intent and are remapped for dark mode in `dark.css`; primitives are theme-agnostic, so using them directly breaks theming. The primitive palette below is listed only so you can see what each semantic token resolves to.

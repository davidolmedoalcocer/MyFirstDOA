Hi Eli, I’m using PBI 494905 (Manage Products) to practice writing a Playwright E2E test. The acceptance criterion I picked says that selecting a product should display its Display Name, Name, and Namespace.

I selected Warehouse Service and confirmed that the portal showed the correct details. The first assertion failed because it targeted the entire Display Name block. Playwright read Warehouse Service followed by Display Name, but the assertion expected only Warehouse Service.

Current assertion
await expect(productManagementPage.displayName.locator).toHaveText('Warehouse Service')

1. Change only the test and check the full block. Use the value and label in the order Playwright reported. This checks both pieces of text and makes the test depend on their wording and order.
await expect(productManagementPage.displayName.locator).toHaveText('Warehouse Service Display Name')

2. Change only the test and check the value. Keep the current locator and read textContent. In this component, that property contains the product value. This checks the value exactly. It doesn’t check whether the value is visible on screen.
await expect(productManagementPage.displayName.locator).toHaveJSProperty('textContent', 'Warehouse Service')

3. Change both the Vue template and the test. In ProductManagementDashboard.vue, keep the existing label and wrap the value in a span with its own test ID.
<infios-text-block data-testid="product-display-name" pretext="Display Name">
  <span data-testid="product-display-name-value">{{ selectedProduct?.displayName }}</span>
</infios-text-block>

Then point the test at that span and check both its visibility and its exact text.
const displayNameValue = productManagementPage.displayName.locator.getByTestId('product-display-name-value')
await expect(displayNameValue).toBeVisible()
await expect(displayNameValue).toHaveText('Warehouse Service')

I’d lean toward option 3 for all three fields because the criterion says the values should be displayed, and this lets the test verify each value directly. Would you make that small Vue change, or does the team prefer to handle this in the test alone?

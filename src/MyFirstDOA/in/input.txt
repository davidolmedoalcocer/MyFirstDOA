- Dozzle: A temporary notification destination remained visible after Docker Compose down and up. The destination was removed after the test.
- Documentation: The README contains the official Dev Portal documentation link.
- Scope: The existing Kiro default region remains us-east-2. The branch contains two commits across eight files. Local settings and generated files outside the PBI were excluded.

Comentario para Mariana
Hi Mariana, here are the basic E2E scenarios I’m proposing for PBI 494908. Do these cover what you’d expect from QA, or would you change or add anything?
1. API — Read configurations for one product version
   Create two versions with different configurations. Request the configurations for the first version and verify that the response contains only its keys and their value definitions.
2. API — Assign an existing configuration and reject a duplicate
   Assign a catalog configuration to a version, then submit the same assignment again. Verify that the first request succeeds, the second returns a conflict, and the version has only one copy.
3. UI — List configurations for the selected version
   Open a version with two configurations. Verify that the rows appear alphabetically by Key without clicking the column header and that Value shows each definition. Switch to a version with no configurations and verify that the table clears.
4. UI — Assign an existing catalog key
   On an In Development version, open Add Configuration, select an existing key, and click Submit. Refresh the page, select the same version, and verify that the key appears once.
5. UI — Create and assign an Expression configuration
   Click +, enter a new key, type {{, and select a field from the suggestions. Save the new key, then submit the assignment. Refresh and verify that the version shows the expression with the selected field still inside {{ }}.
6. UI — Create and assign a Generated configuration
   Click +, enter a new key, select Generated, and choose Hex and 32. Save the new key, then submit the assignment. Refresh and verify that the row shows the selected format and length.
7. UI — View configurations on Released and Deprecated versions
   Open a version in each state. Verify that existing configurations remain visible and that the user cannot add, edit, or remove them.
8. UI — Cancel or confirm removal
   On an In Development version, start removing an assigned configuration. Cancel and verify that the row remains. Repeat and confirm, then refresh and verify that the row is gone from that version.
9. UI — Copy configurations using From Version
   Create a version using From Version and choose a source with two configurations. Open the new version and verify that both keys and their definitions match the source.

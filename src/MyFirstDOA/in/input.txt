Corrige el alta de configuraciones en Product Management → Configurations → Assign Configuration → + → Add Configuration. Si ya existe una configuración llamada Region y el usuario pulsa Submit con region, el formulario debe mostrar que la llave ya existe, conservar lo escrito y evitar que se cree una segunda configuración. La comparación debe ignorar mayúsculas y minúsculas, incluso cuando Region aún no esté asignada a la versión seleccionada.

El alcance autorizado es el alta desde esta pantalla. Usa el catálogo de configuraciones para comprobar el duplicado. La lista Select Key omite las configuraciones ya asignadas, por lo que usarla como única fuente dejaría casos sin detectar.

Verifícalo en el navegador con una prueba básica de Playwright. Crea una configuración propia con una llave única que empiece por Region. Desde +, intenta crearla otra vez cambiando solo Region por region. Comprueba que aparece el mensaje y consulta la API para confirmar que solo existe la configuración original. Limpia los datos de la prueba.

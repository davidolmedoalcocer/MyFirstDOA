# Investigación técnica: problema de autenticación SSO y cookies entre TrackGuard Portal y CSR Web UI

Actúa como un **Senior Software Engineer especializado en .NET, autenticación, Single Sign-On (SSO), middleware, cookies, JavaScript y debugging de aplicaciones web**.

Necesito que realices una investigación exhaustiva del problema de autenticación que estamos experimentando con CSR Web UI.

Tienes acceso a tres proyectos abiertos en el workspace:

1. **CSR Web UI:** aplicación que presenta el problema.
2. **TrackGuard:** portal principal que inicia el proceso de autenticación y redirección.
3. **Policy Search Portal:** aplicación donde la integración funciona correctamente.

Quiero que analices los tres proyectos, compares sus implementaciones y determines por qué CSR Web UI no está generando correctamente su cookie de autenticación.

## 1. Contexto del problema

Estamos integrando CSR Web UI con TrackGuard Portal siguiendo la guía de integración de PG Portal elaborada por Robbie.

Como referencia utilizamos Policy Search Portal, que ya tiene implementada esta integración y funciona correctamente.

**Comportamiento correcto — Policy Search Portal**

- Application ID: `119`.
- El usuario inicia sesión en TrackGuard Portal.
- Selecciona Policy Search Portal.
- TrackGuard genera y envía el interop token.
- La aplicación recibe y procesa el token.
- Se genera correctamente la cookie `Portal.App.119`.
- El usuario puede acceder a la aplicación.

**Comportamiento incorrecto — CSR Web UI**

- Application ID: `124`.
- El usuario inicia sesión en TrackGuard Portal.
- Selecciona CSR Management.
- TrackGuard utiliza correctamente el Application ID `124`.
- Se genera el interop token.
- La redirección hacia CSR Web UI funciona.
- El middleware de CSR Web UI recibe el interop token.
- El código intenta establecer la cookie `PortalInterop`.
- Sin embargo, **la cookie `Portal.App.124` no aparece**.
- En el navegador aparecen cookies correspondientes a `Portal.App.119` y `Portal.App.0`, pero no la correspondiente a `124`.
- El código que espera encontrar la cookie `Portal.App.124` termina alcanzando su timeout.

Hasta ahora no se ha identificado una excepción que explique el problema.

Importante: los nombres de cookies anteriores provienen de la investigación inicial. Confirma sus nombres exactos revisando el código.
